# دفتر الحسابات — مصاريف ومرتبات المحل

تطبيق ويب تقدمي (PWA) صغير وخفيف لتدوين وتخزين **المصاريف التشغيلية**
و**مرتبات الموظفين** لمحل الكهربائيات المنزلية. جميع البيانات تُحفظ محلياً
في المتصفح (`localStorage`) فقط — لا يوجد خادم، ولا اتصال بالإنترنت مطلوب
بعد أول تحميل.

- **اللغة:** عربي (واجهة RTL بالكامل)
- **البنية:** بدون أدوات بناء — HTML / CSS / JavaScript خالص، يُنشر كملفات ثابتة
- **الاعتماديات:** لا مكتبات خارجية، لا CDN (باستثناء خط Cairo من Google Fonts)، لا أدوات تتبع

هذا المجلد (`costs-app/`) تطبيق مستقل قائم بذاته داخل هذا المستودع، منفصل
تماماً عن تطبيق FLOW (إدارة الطلبات) الموجود في جذر المستودع.

## الرابط المباشر

بعد تفعيل GitHub Pages لهذا المستودع (Settings → Pages → Source:
"GitHub Actions")، يُنشر التطبيق تلقائياً مع كل push على `main` على:

**https://baltamar.github.io/flow/costs-app/**

## الوظائف

- **لوحة التحكم:** إجمالي المصاريف التشغيلية، إجمالي المرتبات، الإجمالي
  العام، عدد المرتبات المدفوعة — لكل شهر، مع تفصيل المصاريف حسب التصنيف
  وآخر الحركات.
- **المصاريف:** إضافة/تعديل/حذف مصروف (تصنيف، مبلغ، تاريخ، طريقة دفع،
  ملاحظات)، بحث وتصفية حسب التصنيف، تصدير الشهر الحالي كملف CSV.
- **المرتبات:** لكل موظف نشط يُنشأ تلقائياً سجل راتب شهري (راتب أساسي +
  مكافأة − خصم = الصافي)، مع تحديد الحالة "مدفوع/غير مدفوع" وتصدير CSV.
- **الموظفون:** إضافة/تعديل/تعطيل/حذف موظف (الاسم، الوظيفة، الراتب
  الأساسي، الهاتف).
- **الإعدادات:** اسم المحل، رمز العملة، إدارة تصنيفات المصاريف، ونسخ
  احتياطي/استيراد كامل للبيانات كملف JSON.
- **PWA:** قابل للتثبيت على الهاتف أو سطح المكتب، يعمل دون اتصال عبر
  Service Worker.

## تشغيل التطبيق محلياً

يحتاج الـ Service Worker إلى `http://` أو `https://`، لذا يُفضّل خادم
ثابت بسيط:

```bash
cd costs-app
python3 -m http.server 8080
# ثم افتح: http://localhost:8080
```

أو بدون تثبيت أي شيء:

```bash
npx --yes http-server costs-app -p 8080
```

يمكن أيضاً فتح `index.html` مباشرة عبر `file://`، مع ملاحظة أن Service
Worker لن يُسجَّل في هذه الحالة (قيد من المتصفح)، لكن باقي التطبيق يعمل
بشكل طبيعي.

## التثبيت على الهاتف

- **أندرويد (Chrome):** القائمة ← "إضافة إلى الشاشة الرئيسية".
- **آيفون (Safari):** زر المشاركة ← "إضافة إلى الشاشة الرئيسية".

## ملاحظة هامة حول البيانات

جميع البيانات (المصاريف، الموظفون، المرتبات) تُخزَّن **محلياً فقط** على
جهاز/متصفح المستخدم. مسح بيانات المتصفح يعني فقدان البيانات نهائياً —
يُنصح بأخذ نسخة احتياطية دورية من تبويب **الإعدادات** (زر "تنزيل نسخة
احتياطية").
